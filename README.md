# ساخت جدول ۵-۱۶ برای دیتابیس انفجارسنگ

این مخزن یک اسکریپت پایتون برای ساخت جدول مشابه تصویر ارسالی دارد. اسکریپت فایل اکسل دیتابیس را می‌خواند، ردیف‌های ناقص را حذف می‌کند، پنج رابطه رگرسیون لجستیک چندجمله‌ای را روی داده‌های آموزشی می‌سازد و تعداد پیش‌بینی‌های صحیح را برای داده‌هایی که در برازش هر رابطه استفاده نشده‌اند، به تفکیک شدت واقعی انفجارسنگ گزارش می‌کند.

## اجرای سریع در Colab یا سیستم محلی

```bash
python rockburst_table_5_16.py --excel 1.main.xlsx --output-prefix table_5_16_counts
```

خروجی‌ها:

- `table_5_16_counts.md`: جدول آماده برای کپی در Markdown/Word.
- `table_5_16_counts.csv`: جدول قابل بازکردن در Excel.

## ستون‌های پیش‌فرض دیتابیس

اسکریپت به صورت پیش‌فرض از این سه متغیر برای مدل رگرسیون لجستیک چندجمله‌ای استفاده می‌کند:

- `Wet`
- `sc/st`
- `sq/sc`

و ستون هدف را از `Actual intensity level` می‌خواند. اگر نام ستون‌ها در فایل اکسل تغییر کرد، می‌توانید هنگام اجرا آن‌ها را مشخص کنید:

```bash
python rockburst_table_5_16.py \
  --excel 1.main.xlsx \
  --features Wet sc/st sq/sc \
  --target "Actual intensity level" \
  --output-prefix table_5_16_counts
```

## خروجی ساخته‌شده برای دیتابیس فعلی

برای فایل فعلی `1.main.xlsx`، تعداد ردیف‌های کامل قابل استفاده در مدل برابر ۵۸۱ ردیف است. اسکریپت خروجی‌های `table_5_16_counts.md` و `table_5_16_counts.csv` را نیز در همین مخزن ساخته است.
